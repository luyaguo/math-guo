第一章 函数极限与连续

一、函数的概念

设 x 与 y 是两个变量， D 是一个给定的数集，若对于每一个 x ∈ D ，按照一定的法则 f ，有一个确定的值 y 与之对应，则称 y 为 x 的函数，记作 y = f(x) ，称 x 为自变量， y 为因变量，称数集 D 为此函数的定义域，定义域一般由实际背景中变量的具体意义或者函数对应法则的要求确定，称 {f(x) ∣ x ∈ D} 为值域。

1 单值函数

事实上，上述定义的函数是单值函数，若给一个 x1 ，对应一个 y1 ；给另外一个 x2 ，对应另外一个 y2 ，这叫一对一。若给定 x1，x2 ( x1 ≠ x2 )，它们对应同一个 y ，则称多对一，所以函数可以一对一，也可以多对一，这叫单值函数。

2 多值函数

若一个 x 对应一个 y1 ，又对应另一个 y2 ，也就是一对多，这叫多值函数。 它不在上述定义中。

我们的研究对象主要是单值函数.

3 如何判断 y = f(x) 是否为单值函数？

铅锤划线法：做铅锤直线，若任意一条铅锤直线与 f(x) 至多有一个交点，则 f(x) 为单值函数。

二、反函数

设函数 y = f(x) 的定义域为 D ，值域为 R .如果对于每一个 y ∈ R ，必存在唯一的 x ∈ D 使得 y = f(x) 成立，则由此定义了一个新的函数 x = ϕ(y) ，这个函数称为函数 y = f(x) 的反函数，一般记作 x = f−1(y) 它的定义域为 R ，值域为 D .相对于反函数来说，原来的函数也称为直接函数。

1 概念解析

第一，严格单调函数必有反函数（充分条件）。比如函数 y = x2(x ∈ [0， + ∞)) 是严格单调函数，故它有反函数

第二，反函数和直接函数的图形是完全重合的。若把 x = f−1(y) 与 y = f(x) 的图形画在同一坐标系中，则它们完全重合。

第三，只有把 y = f(x) 的反函数 x = f−1(y) 写成 y = f−1(x) 后，它们的图形才关于 y = x 对称（前提：符合铅锤画线法），事实上这也是字母 x 与 y 互换的结果。
